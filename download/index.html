Mainbrella is in development.

Mainbrella is a sandbox service for AI agents, built on Cloudflare Containers. Create isolated Linux workspaces, run code, and restore files for the next task.

Our prototype passed create, resume, and 100-sandbox concurrency tests. Public sandbox access is not available yet. Website sign-in and Pro subscription checkout are available in the pricing section; subscribing does not provide sandbox access yet.
