About Mainbrella

When Cloudflare introduced Sandboxes, we saw a brand-new foundation for running agent code—and an opportunity to build a better agent sandbox system than the options already out there. That’s why we started Mainbrella.

The opportunity

Agents need a place to run commands, install dependencies, and work with files. Cloudflare’s sandbox infrastructure provides isolated environments for that work. Its Sandbox documentation shows how those building blocks can support coding agents, code interpreters, and development previews.

We saw room to turn that infrastructure into a service developers could use directly: create a sandbox, connect to it, give an agent access, and stop it when the work is done. Mainbrella builds on Cloudflare Containers, the infrastructure behind Cloudflare’s container sandboxes.

What better means to us

We want setting up an agent’s workspace to be straightforward. That means a clear way to create and manage containers, access through familiar tools, and pricing you can understand before you run anything.

Today, Mainbrella provides managed Linux containers with SSH and browser terminals, an API for automation, and fixed monthly plans with explicit limits. You can connect yourself or let an agent use the same container workflow.

We’re early. Our goal is to make the full experience of running an agent in a sandbox easier, from the first connection to cleanup. Cloudflare’s new infrastructure gave us a reason to start building.
