Local access. One useful view.

  1. 01

    Use local credentials

    The planned desktop app uses existing AWS profiles or SSO and local Google Cloud credentials. Its first inventory is read-only.

  2. 02

    Find and group resources

    Search across providers, then manually group the resources that belong to each application.

  3. 03

    Inspect, then go deeper

    See provider metadata in context and follow a resource’s deep link to its AWS or Google Cloud console for full details.

Designed to stay local.

Mainbrella is planned as a local-first desktop app: credentials stay on your machine, and the app talks directly to providers. AWS and Google Cloud start with read-only inventory; no infrastructure changes are part of this first scope.
