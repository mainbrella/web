Usage and deadlines

One compute-unit hour runs one unit for one hour. Small uses 6 units/hour; an XL uses 28. Running and provisioning time, including idle time, consumes the allowance. Runtime is reserved before launch up to the session deadline; stopping releases unused reserved runtime after reconciliation. Requests rejected before reservation use no compute allowance. Ambiguous or unreadable starts retain their reservation until reconciled. Usage resets each UTC month without rollover; changing plans, canceling, or resubscribing does not reset usage. Sessions also end at the UTC month boundary or when their allocated runtime expires. No automatic overage charges or top-ups are enabled.

Both the container ceiling and concurrent compute-unit ceiling apply, including pending starts. For example, Builder can run one XL or four Small machines; Pro can run four XL machines; Scale can run 22 XL machines. Each combination must also fit the available monthly runtime allowance.

Starts are shared across the account and reset at the start of each UTC month. Failed starts count. Stopping, changing plans, canceling, or resubscribing does not reset usage. A pending start counts toward concurrency; a request rejected at capacity does not reserve a start.

Sessions end at the hard deadline or the paid period recognized at creation, whichever comes first. Upgrades and renewals do not lengthen running sessions. Activity extends only the idle deadline; polling and SSH token issuance do not.

Downgrades and cancellation take effect at renewal. An effective downgrade can stop excess containers and shorten deadlines. Loss of paid access stops containers.

Current platform boundaries

Ordinary stop discards unsaved files; save a filesystem workspace before stopping. JavaScript and Python SDKs are published. Process/memory resume, arbitrary custom machine configurations, team seats, audit exports, advanced logs, and priority capacity are not currently available. Outbound internet access is enabled; customer-configurable egress restrictions and a guaranteed residency region are not offered.

Self-service plans have no uptime SLA or automatic service credits. Monthly fees are fixed, with no compute usage billing. See Terms and Status.
