Agent setup

Mainbrella's agent skill covers account setup, project detection, image selection, integration, verification, and troubleshooting. It uses the same HTTP API as your own application.

Give your agent the instructions

Read https://mainbrella.com/SKILL.md and follow its Quick Setup.
Integrate Mainbrella using this project's existing conventions.
Verify foreground and managed execution, cancellation and binary file transfer, then clean up the
container created by the verification. Preserve existing containers.

Provision MAINBRELLA_API_KEY separately through your secret manager or environment loader. Do not paste a key into the prompt.

Install locally

Download and inspect the Mainbrella skill archive (0.1.0), then extract its mainbrella-containers folder into your agent’s skills directory. It contains SKILL.md, API.md, and an indexed reference tree. See the Codex, Claude Code, and HTTP tool recipes for setup and verification.

Verify the integration

Follow the Quickstart. The doctor makes read-only checks; verification consumes one start and must report matching hello output, exit code zero, verified binary transfer, managed streaming, cancellation, and completed cleanup. Keep a failed or ambiguous creation key for reconciliation before trying again.
