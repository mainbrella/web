Compute placement and regions

Containers run on Cloudflare infrastructure. Mainbrella does not offer a customer-selected compute region or guaranteed data residency. The API does not publish the region of an individual container; Cloudflare’s network footprint is not a list of guaranteed Mainbrella regions.

Internal networking

Private Services is a local HTTP prototype for connecting independently managed machines through named .internal endpoints. Explicit network membership and exact-generation checks govern access; a backend needs no public preview. Production support has not been qualified. Require networking.privateServices: true from GET /capabilities. Only bounded plain HTTP is supported, with no arbitrary TCP, HTTPS, WebSockets, private IPs or direct database protocols.
