Cloudflare supplies the runtime. Mainbrella supplies the service.

Cloudflare Containers is infrastructure for running container workloads through Workers and Durable Objects. Mainbrella adds customer accounts, billing, named API keys, machine lifecycle controls, command and file APIs, browser terminals, SSH, and previews.

A hosted Mainbrella account does not require your own Cloudflare account or Worker deployment. If you need direct control of your Worker architecture, you can use Cloudflare Containers directly or self-host Mainbrella.

Before you start

Do I need a Cloudflare account?

Not for Mainbrella Hosted. Sign in, choose a plan, create an API key, and use the managed service. Self-hosting requires your own Cloudflare infrastructure.

How are environments isolated?

Cloudflare runs each container in a separate microVM. Mainbrella checks account ownership and container generations at the API boundary. Read the security details for the service’s controls and limitations.

Is the $5 plan unlimited?

No. Builder includes 250 compute-unit hours, 1,000 starts, and up to five concurrent containers within 28 concurrent compute units. Sessions last up to one hour with a 10-minute idle timeout. Compare plans for larger workloads.

Can I run a permanent server here?

Mainbrella’s current machines are temporary, with idle and hard session deadlines. Save a filesystem snapshot or export your files before stopping. For permanent services, check those lifecycle requirements first.
